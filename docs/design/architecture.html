Deployment and processes

Every device reaches the system through one public HTTPS name, because browsers allow WebGPU only on secure pages. Only the swarm proxy publishes a port on magserver. There is no separate queue service: the work queue is the units table, claimed inside PostgreSQL transactions.

  • Why two proxies. Kant's Caddy already owns ports 80 and 443 and holds the certificate. The swarm proxy keeps the site and the API on one origin, exactly as Vite does in development.
  • Simulated workers are real clients. sim-worker speaks the same protocol as a browser, with the Rust reference kernels. The chaos panel's cheaters connect the same way.
  • Commits skip the disk wait. A PostgreSQL crash can lose the last fraction of a second of results. Their leases then expire and the units are computed again.

One worker session, message by message

A device holds one WebSocket. Every message is JSON, typed in crates/protocol. The coordinator replies to each request at once, and that lets the browser treat a long silence as a dead connection.

  • The coordinator can push at any time. A new control arrives when the owner pauses the network or its working hours close. The chaos panel can also kill a session or cut it off silently.
  • Pings don't count as life. Only protocol messages reset the 30 s idle timer, since a proxy may keep pinging long after the worker is gone.
  • The browser gives up after 20 s with no reply. A phone that slept with the page frozen may never see the socket close, so it reconnects with back-off of up to 15 s.

How a unit is verified

Anyone can join, so any result may be wrong on purpose. Both decisions happen inside a single database transaction. On the left, claim_unit chooses what a device gets. On the right, complete_lease decides what its answer is worth.

Unit, lease and job states

These are the exact values allowed by the CHECK constraints in the migrations. A unit stays pending until enough copies of it are leased out, so a replicated unit can be handed to a second client while the first is still computing.

Inside one browser tab

The page thread manages the connection and decides when to compute. Kernels run in a Web Worker, and only kernels shipped with the site can run. A job carries parameters and never code, so the grid can't be turned into a botnet.

One source of truth for both sides

The coordinator and the browser have to compute the same answers, and they have to agree on every message. Four source trees feed both sides. CI fails if a generated file drifts from its source.
